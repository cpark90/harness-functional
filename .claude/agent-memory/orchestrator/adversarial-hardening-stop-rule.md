# 적대적 강화 라운드의 정지 규칙 (무한 회귀 끊기)

vnv에 "새 우회를 창안하라"고 지시하면 **매 라운드 새 결함이 나온다**(실측: 4 → 3 → 5건).
강화가 효과 있다는 증거이지만, 종료 조건을 명시하지 않으면 라운드가 끝나지 않는다.

- **발견을 두 계열로 분류시켜라**: (가) **일상 경로** — 편집·복사·병합·저장 같은 평범한
  사용으로 도달 가능. (나) **경계 바깥** — 저장 파일에 직접 쓸 수 있는 주체만 할 수 있는 일
  (손으로 식별자 기입, 남의 유효 증거 이식). (나)는 서명·무결성 태그 없이는 원리적으로 막을
  수 없으므로 **방어 대상이 아니라 신뢰 경계**다.
- **차단 사유는 (가)만**: vnv 브리프에 두 문장을 함께 넣는다 — "자기 세션이 세운 조건을
  완화하지 마라" + "**경계 바깥 항목을 근거로 차단을 연장하지도 마라**". 한쪽만 넣으면
  판정이 느슨해지거나(전자 누락) 영원히 안 끝난다(후자 누락).
- **경계는 문서에 못박고, 자의성은 vnv가 검증한다**: README/REPORT 한계표에 경계 문장을
  쓰게 하고, 판정 항목에 "경계를 근거 없이 넓혀 결함을 숨기는 형태면 CONFIRMED로 보고"를
  넣는다. 그래야 정지 규칙이 도피처가 되지 않는다.
- **같은 구조가 그래프 쪽에도 있다**: "쓸 것이 실재할 때만 저작"(alternativeOf 0쌍, 잔존
  개념에 새 Concept 신설 안 함), "소비를 켜는 조건은 **가중이 고칠 랭킹 결함이 실측되는
  것**"(anchorConfidence 선언 전용 유예). 유예를 취향이 아니라 **측정 가능한 기준**으로
  바꾸는 것이 공통 형태다 — [[cross-session-lane-protocol]] 참조.
- **원리적 불가능은 결정이 아니라 제약**: 두 요구가 동시에 만족 불가함이 측정으로 증명되면
  (예: 블록 이동 복구 ↔ 재타이핑 거절 — 두 편집의 CRDT 업데이트가 byte 동일) 라운드를 더
  돌리지 말고 **사용자 결정 항목으로 올린다**(선택지에 대가를 수치로).

## 재질의 항목의 표기 함정 (실제로 사고를 냈다)

원 항목의 선택지 문자를 **재질의에서 재사용하면 안 된다**. 실측 사고: 원 항목의 `(b)`는
"안정 블록 id", 재질의의 `(b)`는 "Loro 스택 교체"였고, 두 채널에서 같은 글자로 **정반대 답**이
와 양쪽 dispatch가 HOLD됐다. 규칙:

- 재질의에는 **문자 대신 이름**을 쓴다(`A. 안정 블록 id` / `B. Loro 스택 교체`).
- 부득이 문자를 쓰면 원 항목과 **다른 기호 집합**을 쓰고(예: 1/2/3), 표로 대조를 싣는다.
- 재질의를 올리기 전에 **원 항목의 최신 상태를 다시 읽어라** — 그 사이 답이 달렸거나
  브리프가 나왔을 수 있다(이번 사고의 절반은 push된 결정을 못 보고 중복 질의한 것).

## "선언 전용 = 중립"은 추론이지 측정이 아니다 (실측 사고)

`ho:Anchor` 개체를 **소비 코드 0줄**인 상태로 저작했더니 검색 팩이 오염됐다: 40질의 중 29개
변화, 한 질의는 36→19 노드로 붕괴, **주석 대상 노드가 자기 anchor에 밀려 탈락**. 경로는
(1) anchor의 prefLabel이 노드·region 라벨을 반복해 lexical seed 상위에 진입(MAX_SEEDS에서
실노드를 밀어냄), (2) 추론된 harness→hasComponent→anchor 엣지 + tokenEstimate 부재 기본비용
으로 rollup 확산.

- 내가 준 실측은 "`grep anchorConfidence tools/*.py` = 0줄"까지였고, 거기서 **"그러면 검색
  중립"이라고 추론**한 것이 빈틈이었다. **선언 전용은 소비 코드에 대한 진술일 뿐, 개체가
  그래프에 존재하는 순간 검색·롤업 경로에는 이미 참여한다.**
- 규칙: 신규 개체군을 저작하는 브리프에는 **"저작 전후 팩 비교"를 게이트로 항상** 넣는다
  (이번에도 그 게이트 덕에 developer가 잡았다). 중립을 주장하려면 byte 비교로 증명한다.
- 오염이 확인되면 **저작을 되돌리지 말고**(승인된 저작분) projection에서 제외하되, 판정
  기준을 "저작 이전과 byte-identical"로 잡아 **검색 의미를 바꾸지 않았음**을 기계로 증명한다.
