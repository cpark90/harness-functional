# 자기보고를 믿지 않는 층 만들기 — plane-editor C1b 차단 해제 (tools/plane-editor)

C1b 판정이 건 조건 3개(문서 정체성 / 저장소 계약 / 끊긴 종단점·orphan 예산)와 Phase 2 F1
(주석 스토어 버전 충돌)을 한 wave에서 닫으며 배운 것. 앞선 두 파일
(`plane-editor-anchor-identity-c1b.md`, `plane-editor-phase2-link-planes.md`)의 다음 단계다.

## 1. 정체성은 "무엇으로 계산하느냐"가 아니라 "언제 발급하느냐"의 문제

레코드를 남의 문서에 붙지 못하게 하려면 문서 id가 필요한데, **콘텐츠 해시는 필요한 성질을
둘 다 어긴다**: 편집하면 값이 바뀌고(생애 안정성), 같은 텍스트의 다른 문서를 같다고 말한다
(파생본 구별). 답은 **생성 시 1회 발급 + 상태 안에 보관**이다.

- 보관 위치는 CRDT 상태(별도 `Y.Map`)여야 편집·저장·재로드·복제본 병합을 통과한다. 파일
  필드는 **사본**으로만 두고 원본은 상태에서 읽는다(파일은 손으로 고칠 수 있다).
- 재임포트·파생본은 새 CRDT라 자동으로 새 id를 받는다 = 원하는 동작이 공짜로 나온다.
- **정체성 없는 상태에 로드 시점 발급 금지** — 그건 출처 날조다. 대신 "아무 레코드도
  바인딩되지 않는" 쪽으로 흐르게 한다.
- 결정론 스위트에서는 발급기를 프로세스 내 단조 카운터로 두되, **커밋되는 산출물**(sample
  store)·**대조 실험**(같은 편집을 여러 갈래로 비교하는 진단)은 id를 호출부가 **명시 고정**해야
  한다. 안 그러면 (a) 산출물 참조가 발급 순서에 흔들리고 (b) 상태에 섞인 id 때문에 업데이트
  해시 비교가 무의미해진다(실제로 G3 결정론이 깨져서 발견).
- 리포트·payload에는 id 값을 싣지 말고 **관계**(같은 문서인가)만 싣는다. 값이 들어가면 두
  번째 측정 패스에서 카운터가 달라져 결정론이 깨진다.
- 문서 상태에 뭔가를 넣었으면 그 자리에 **주석 데이터가 새지 않는지** 게이트로 박아라
  (메타 맵 키가 정체성 하나뿐인지 확인). 안 그러면 standoff 순수성 주장이 약해진다.

## 2. 자기보고 증거는 **다른 selector와 교차 검증**해야 증거다

"파일 version이 N이면 이 필드를 믿는다"는 방어가 아니다 — 그 version도 마이그레이션이 쓴다.
실측된 회귀: v1→v2 승격 스크립트가 캡처 시점 state vector를 **현재 값**으로 채우자 닫았던
오해소가 그대로 부활했다.

- **시점(state vector)이 아니라 이름표(character id)로 바꿔라.** Yjs 문자열 item id는 길이만큼의
  clock 구간이고 item이 쪼개져도 문자의 clock은 보존된다(실측). 그래서 앵커 범위를
  `{client, clock, length}` 런으로 저장하면 "그때 그 문자가 남았는가"를 직접 물을 수 있다.
- 이름표의 힘은 **베껴 넣을 수 없다**는 데 있다: 저장된 `exact` 길이와 맞아야 하고(블록 구분자
  `\n`은 CRDT 문자가 아니므로 빼고 센다), 저장된 state vector 기준으로 전부 preexisting이어야
  한다. 마이그레이션이 현재 범위에서 복사하면 둘 중 하나에 반드시 걸린다(길이가 같아도 SV에서
  걸린다 — 두 검사가 서로 다른 위조 모양을 잡는지 진단으로 각각 보여라).
- 손상된 증거(`corrupt`)와 부재한 증거(`absent`)를 **가려라**. 손상은 계약 위반이라 스토어가
  강등해야 하고, 부재는 정상적으로 있을 수 있다(블록 경계를 걸친 앵커 등). 한 덩어리로 묶으면
  정상 레코드까지 강등된다.
- 마이그레이션 함수에 **승격 분기를 만들지 마라**. 강등 전용이면 "채워넣기 경로가 없다"를
  코드로 증명할 수 있고, 진단이 위조 스토어 N모양을 실제 파일로 만들어 못박는다.
- 정체성처럼 **외부 사실**(레코드가 이 document.json 옆에 있다)에서 오는 값은 강등본에도 붙여야
  한다. 안 그러면 옛 레코드가 규칙 0에서 통째로 죽어 하위호환 경로가 **측정 불가능**해진다
  (기존 시나리오가 vacuous가 된다 = 판정자가 바로 잡아낸다).

## 3. 정밀도 게이트에는 재현율 예산을 붙여라

"오해소 0"만 재는 게이트는 전부 orphan으로 만들어도 통과한다. 그래서 **편집 후에도 앵커
텍스트가 문서에 남는 흔한 조작**(이동 2-tx/1-tx, 병합, 분할, undo, 대조군=범위 안 삽입)을
정식 시나리오로 넣고 조작별 orphan율을 리포트에 **게시**한다.

- 기대값을 orphan으로 낮추지 마라 — 손실이 표에서 사라진다. 통과가 아니라 계측으로 둔다.
- 게이트는 값이 아니라 **측정했는가 · 그 범위에서 오해소 0인가 · 대조군은 살아남는가**를 본다.
- 텍스트 동일성만으로는 부착 **위치**를 못 잰다(같은 문장이 두 번 나오면 남의 자리도 "정답"이
  된다). 앵커 텍스트가 편집에 닿지 않은 시행에 한해 `landedOffset ∈ 출현 위치` 를 같이 세면
  정밀도 주장이 훨씬 강해진다. 범위 안 삽입·부분 삭제처럼 앵커 텍스트 자체가 바뀌는 시나리오는
  이 지표에서 **제외**해야 오탐이 없다.
- undo 시나리오는 UndoManager의 `trackedOrigins`에 편집기 origin(y-prosemirror는 `ySyncPluginKey`)을
  넣지 않으면 아무것도 되돌리지 않는다 = 조용히 "그냥 삭제"로 퇴화한다. 시나리오 안에서 문서
  텍스트로 **복원됐는지 검증**하고 아니면 throw.
- 레인별로 값이 갈리는 것 자체가 정보다: 저장 시 재캡처가 도는 경로에서는 병합·분할이 안
  끊기고, 옛 레코드를 들이대는 경로에서만 끊긴다.

## 4. 남의 평면이 소유한 상수는 강요하지 말고 **협상**하라

검사기가 자기 스토어 버전을 남의 스토어(주석 평면)에 적용해서 실사용 파일이 통째로 exit 2가
났다(F1). cap 계약 표면에서 배운 "값 복제 금지"의 반대 방향 실수다.

- 읽을 수 있는 버전 **집합**을 선언하고, 못 읽는 버전은 사유와 함께 거절한다(조용한 통과 금지).
- "읽기"와 "바인딩"을 가른다: 옛 버전은 읽히지만 문서 정체성이 없어 종단점을 못 묶는다는 것을
  **전용 사유 코드**로 말해야 한다(그냥 "없는 레코드"라고 하면 원인이 뭉개진다).
- 소유 모듈의 현재 버전을 읽어(선언 한 줄 파싱) 자기 집합을 넘어섰으면 **알람**을 울린다.
  값을 베껴 오는 게 아니라 "검사기를 가르쳐라"는 신호다. 실행 의존(node 호출)을 늘리지 않고도
  드리프트를 잡는 값싼 방법.
- 판정을 실측으로 못박으려면 **실사용 스토어를 물려 PASS를 재는 체크**를 스위트에 넣는다.
  그 링크 fixture가 겨냥하는 문서 id는 스위트가 명시 고정한 값이어야 안 흔들린다.

## 5. 링크 종단점: id는 문서 안에서만 유일하다 / 끊김은 상태다

- 주석 종단점은 `{plane, ref, document}`. `a1`은 문서마다 있으므로 문서를 빼면 종단점이 남의
  문서를 가리킨다. 규칙은 셋으로 갈라야 원인이 보인다: `endpoint-document-missing`(문서 미표기) /
  `endpoint-document-mismatch`(다른 문서에 있음) / `record-endpoint-missing`(아예 없음).
- 종단점 앵커가 orphan이 되는 것은 **위반이 아니라 상태**다. 링크를 지우면 소실, 다시 겨누면
  오부착이므로 **보고**만 한다(exit 0 유지, `brokenEndpoints`). 대신 상태를 **모르는** 것은 위반으로
  잡는다(레코드에 측정된 `anchorState`가 없으면 링크가 "아직 붙어 있다"고 가정하게 된다).
- 그 상태를 링크 레코드에 복제하지 마라 — 복제하는 순간부터 낡는다. 끊김은 언제나 종단점에서
  파생한다.
- negative control은 계속 **한 곳만 변형 + 위반 1건**을 지킨다. control이 바뀌면 negative를
  스크립트로 재생성해 `diff`가 한 줄로 남게 한다(대조군의 값은 그 한 줄에서 나온다).
- 언어 정책 스캔(G5)의 파일 목록이 손으로 나열돼 있으면 새 파일이 조용히 빠진다. 스토어·fixture
  디렉토리는 **정렬 순회**로 훑고, 기호 allowlist 확장은 그때 한 번에 명시적으로 한다.
